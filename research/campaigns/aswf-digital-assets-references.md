# ASWF Digital Assets template references

The Index admits the 1.0 and 1.1 templates from the pinned Academy Software Foundation repository for documentary lookup. Each version has its own entity and scoped SPDX 3.29.0 correspondence. The decoded SPDX licenseText matches its corresponding project template after replacing typographic double quotation marks with straight quotation marks. Both verification phases also compared each template with the other edition.

The SPDX 1.0 detail uses “ASWF Digital Assets License version 1.0”. The Index uses “ASWF Digital Assets License 1.0” as its display name. The first research and independent review both rejected the earlier claim wording that attributed the Index name to SPDX. The revised correspondence preserves the distinction. These template references identify no individual asset's rights holder or terms. Installation and reuse require separate evidence.
