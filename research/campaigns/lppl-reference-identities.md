# LaTeX Project Public License reference editions

The index identifies the exact publisher references for LPPL 1.0, 1.1, 1.2 and 1.3a and links them to the corresponding entries in SPDX List Data 3.29.0. The SPDX entries cite HTTP locators for the same publisher host and edition-specific paths as the retained HTTPS references. Each claim records its source revision and its limits on edition correspondence, work-specific grants and reuse.

Two independent executions also supported the documentary identity of the captured LPPL 1.3c publisher plaintext. The SPDX entry cites a different publisher path and an OSI page. The cited publisher path returned HTTP 404 over HTTPS. A separate pair of executions supports the Index's documentary association of LPPL-1.3c with the pinned publisher reference. SPDX and the publisher name the same edition and header date. Both representations contain the passage on derived works that are not replacements. Their specimen notices differ in year, URL scheme, named LPPL version and distribution date.
