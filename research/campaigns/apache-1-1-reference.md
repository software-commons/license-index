# Apache License 1.1 publisher reference

The Apache Software Foundation example contains the heading “The Apache Software License, Version 1.1.” Its license body and the SPDX 3.29.0 Apache-1.1 licenseText field have the same ordered case-folded alphanumeric tokens. The comparison excludes the publisher preface, comment delimiters, punctuation and whitespace. The SPDX seeAlso locator differs from the publisher plaintext URL. The Index classifies the exact publisher example as active for documentary lookup.
